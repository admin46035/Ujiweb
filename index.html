Konfigurasi Web App URL (Google Apps Script)

Didapat setelah menerapkan (deploy) skrip Code.gs sebagai Web App dengan akses "Anyone".
Panduan Singkat Deploy Google Apps Script:
  1. Buka Google Spreadsheet target (Klik di sini).
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Tempelkan seluruh kode dari file Code.gs.
  4. Klik tombol Deploy (Terapkan) > New Deployment (Penerapan Baru).
  5. Pilih tipe Web App, atur Execute as: Me dan Who has access: Anyone.
  6. Salin Web App URL yang dihasilkan dan tempelkan pada kolom di atas, lalu klik Simpan URL Endpoint.
Pemberitahuan berhasil!
